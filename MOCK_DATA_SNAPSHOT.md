# Mocked-data snapshot

This branch is a frozen checkpoint of the app taken right before real API
integration started on `main`. Every section below is fully built out and
navigable, but backed entirely by mocked data:

- Lifecycle
- Rooms
- Today
- Goals
- Digest
- Inbox
- Handoff
- Leakage Map
- Funnel

Not meant to be merged. Kept open as a reference point — check it out or
open its Vercel preview deployment to see the full app as it looked with
mocked data, for comparison as real API work replaces the mocks on `main`.
